# Paint Canvas — Aplicación de Dibujo con HTML5 Canvas

Aplicación de pintura interactiva construida sobre la API Canvas de HTML5. Permite dibujar a mano alzada con selección de color, tamaño de brocha, tipo de punta y descarga de la imagen resultante.

## Tecnologías

- HTML5 Canvas API
- JavaScript (vanilla)
- CSS3

## Funcionalidades

- **Dibujo a mano alzada** — tracking del ratón para trazar líneas suaves
- **Selección de color** — color picker integrado
- **Tamaño de brocha** — control deslizante para ajustar el grosor
- **Tipo de punta** — redonda y cuadrada
- **Pintura abstracta** — modo de relleno con circulos aleatorios
- **Inserción de imágenes** — carga y muestra imágenes sobre el canvas
- **Botón guardar** — descarga el dibujo como archivo PNG
- **Integración con IA** — versión que conecta con un modelo de lenguaje
